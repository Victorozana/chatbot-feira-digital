# Documentação Visual

Esta pasta é reservada para armazenar imagens complementares, capturas de tela e diagramas da arquitetura do projeto.

Caso queira adicionar uma imagem de fluxo:
1. Salve sua imagem aqui com o nome `arquitetura.png` (ou `.jpg`).
2. No arquivo `README.md` raiz, referencie-a com:
   ```markdown
   ![Arquitetura da Solução](docs/arquitetura.png)
   ```
